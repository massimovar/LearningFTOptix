Ubiquity New Releases

Release history for UBIQUITY secure remote access platform

v14.4

2026
Key Features & Enhancements
  • Local Web-Based Remote Desktop: Access and mirror HMI screens directly from any browser-enabled device on the local network without installing UBIQUITY Tools.
  • Device Statistics Dashboard: Centralized visibility into device types, versions, and connection status for easier fleet monitoring.
  • USB Device Configurator: Devices provisioned through USB using standardized System Manager JSON configuration files.
  • Single Email, Multiple Domains: Authenticate across multiple domains using the same email account, including 2FA and external auth.
  • Improved VPN Throughput: Enhanced virtual Ethernet adapter boosts VPN performance ~150% vs v14.3.
  • Hidden Parent Folders: Subdomain users only see authorized resources.
  • Improved MAC Address Handling: Physical MAC addresses consistently displayed, filtering out virtual/bridge interfaces.
  • Infrastructure & Scalability: Updated Access/Relay servers, migration to TLS 1.3.
  • Kubernetes-Based Private Server: UBIQUITY Private Server now supports Kubernetes container architecture.

v14.3

2025
Key Features & Enhancements
  • VNC Support for Sub-devices: Integrated VNC client enables direct access to subdevices without external tools.
  • User Invitation Enhancement: Invite users without UBIQUITY accounts; new management page.
  • Least Privilege for Windows Runtime: Runtime operates with restricted privileges.
  • Sub-device Copy/Paste: Duplicate sub-device configurations across runtime devices.
  • Ethernet Interface Labels: IP addresses linked to Ethernet interfaces for clearer diagnostics.
  • Quick Action Toolbar: Faster access to key functions, improved hover buttons and context menus.
  • Member Of & Show Permissions: Better visibility into user roles and permissions.
  • French Language & In-App News: French UI support and integrated news feed.
  • SD/USB File Transfer on Embedded Devices: Explorer tab supports file management from SD/USB (fw 7.0+).

Runtime Discontinuation Schedule

  • May 2025: Runtimes < 3 blocked
  • Jun 2025: Warning for Runtimes < 5
  • Jul 2025: Control Center disconnects
  • Mar 2026: Runtimes < 5 blocked
  • Apr 2026: Warning for Runtimes < 8
  • Oct 2026: Runtimes < 8 blocked

v14.2

2024
Key Features & Enhancements
  • Infrastructure — Relay Servers: Improvements in relay server reliability and scaling.
  • Platform — iOS App: New/updated Ubiquity iOS application with VPN feature.
  • Platform — Localization: Added Italian, Spanish and German language support.
  • Runtime — Least Privilege for Ubuntu22: Reduced runtime privileges for improved security.
  • Runtime — Embedded Browser for Windows 10 IoT: Embedded browser support for Windows IoT.
  • Runtime — Docker Container support: Dockerized runtime options for flexible deployment.
  • Local Connection — UI Improvements: Better local connection experience.
  • Ubiquity Manager — Login Improvement: Improved login flow and authentication handling.

v14.1

2024
Key Features & Enhancements
  • Web-Based Runtime UI: New UI for Windows/Linux with password protection.
  • Windows 11 Support: Full compatibility with Windows 11.
  • Local Connection on Ubuntu 22: LAN-based access now supported on Ubuntu 22.
  • Chinese Localization: Chinese language added across Manager, Runtime, and Tools.
  • Optimized Relay Server Selection: Improved VPN performance via smarter server selection.
  • New SDK for VPN & File Transfer: SDK + Web APIs enable secure remote access and file exchange.

v14

2024
Key Features & Enhancements
  • Sub-device Access: Manual definition and direct access to subnetwork devices via VPN and embedded browser.
  • Invite User to Device: Invite domain users directly to devices with configurable expiration.
  • UI Improvements: Reorganized contextual menus and enhanced search.
  • .NET 8 Adoption: Manager, Tools, and Runtime updated to .NET 8.
  • Mandatory Runtime Update: Devices running Runtime < 3 blocked from server access.
