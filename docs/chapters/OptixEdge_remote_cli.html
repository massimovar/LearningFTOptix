Security: Plain Docker TCP on port 2375 is not encrypted or authenticated. Enable it only on an isolated trusted network, restrict allowed interfaces, and disable remote management immediately after use.

Enable remote management

  1. In System Manager, open Docker > Remote Management.
  2. Select the connection type and only the network interface required for the maintenance session.
  3. Record the OptixEdge IP address and confirm the preparation computer is on the intended trusted network.

Point the Docker CLI to OptixEdge

Windows PowerShell

$env:DOCKER_HOST = "tcp://optix_edge_ip:2375"
docker version
docker ps

Linux or macOS

export DOCKER_HOST=tcp://optix_edge_ip:2375
docker version
docker ps

If the server section in docker version identifies the OptixEdge engine, commands such as docker compose up -d, docker logs, and docker inspect now target the device.

End the maintenance session

Windows PowerShell

Remove-Item Env:DOCKER_HOST
docker context show

Linux or macOS

unset DOCKER_HOST
docker context show
  1. Disable Docker remote management in System Manager.
  2. Verify the local CLI no longer reaches OptixEdge.
  3. Review the deployed containers and published ports before returning the device to service.
