USB import accepts one image archive and one docker-compose.yaml. For a multi-container stack, save all required images into the same archive.

General workflow

  1. Use a USB drive formatted as FAT32, exFAT, or ext4.
  2. Install Docker or Docker Desktop on the preparation computer.
  3. Pull images explicitly for linux/arm64.
  4. Save the images into one .tar archive.
  5. Place the archive and docker-compose.yaml in the USB root.
  6. Connect the drive to OptixEdge and choose Import docker image via USB in System Manager.

Example: MySQL and phpMyAdmin

Prepare the image archive

docker pull --platform linux/arm64 mysql:8.4
docker pull --platform linux/arm64 phpmyadmin:5
docker save -o mysql_phpmyadmin.tar mysql:8.4 phpmyadmin:5

Create docker-compose.yaml

services:
  mysql:
    image: mysql:8.4
    container_name: mysql-lab
    environment:
      MYSQL_ROOT_PASSWORD: CHANGE_ME_ROOT_PASSWORD
      MYSQL_DATABASE: example_db
      MYSQL_USER: example_user
      MYSQL_PASSWORD: CHANGE_ME_USER_PASSWORD
    volumes:
      - mysql_data:/var/lib/mysql
    restart: unless-stopped

  phpmyadmin:
    image: phpmyadmin:5
    container_name: phpmyadmin-lab
    depends_on:
      - mysql
    environment:
      PMA_HOST: mysql
      PMA_PORT: 3306
    ports:
      - "8090:80"
    restart: unless-stopped

volumes:
  mysql_data:

Copy mysql_phpmyadmin.tar and docker-compose.yaml to the USB root, import them, then verify phpMyAdmin at http://optix_edge_ip_address:8090.

Example: Mosquitto MQTT broker

The no-auth configuration below is suitable only for an isolated lab network. Configure authentication and TLS before using MQTT in production. 
docker pull --platform linux/arm64 eclipse-mosquitto:2
docker save -o mosquitto.tar eclipse-mosquitto:2
services:
  mosquitto:
    image: eclipse-mosquitto:2
    container_name: mosquitto-lab
    command: mosquitto -c /mosquitto-no-auth.conf
    ports:
      - "1883:1883"
    volumes:
      - mosquitto_data:/mosquitto/data
      - mosquitto_log:/mosquitto/log
    restart: unless-stopped

volumes:
  mosquitto_data:
  mosquitto_log:

After import, confirm the container is running and test port 1883 from an authorized client on the same trusted network.
