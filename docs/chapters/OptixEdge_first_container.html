Lab example: Replace every CHANGE_ME value before deployment. Do not reuse tutorial credentials in production.

Before you begin

  1. Open https://optix_edge_ip_address and sign in to System Manager.
  2. Go to Docker > Services, enable Docker Engine, and reboot OptixEdge.
  3. Choose container storage under Docker > Container Storage. Use a suitable Micro SD card when application data should not consume internal eMMC capacity.
  4. Enable Embedded Portainer CE under Docker > Services, then reboot again if requested.

Deploy the stack

  1. Open https://optix_edge_ip_address:9443 and accept the device certificate only after confirming the address is correct.
  2. Create the Portainer administrator account at first login.
  3. Select the local environment, open Stacks, and choose Add stack.
  4. Name the stack mysql-lab.
  5. Paste the compose file below, replace the credentials, and deploy the stack.
services:
  mysql:
    image: mysql:8.4
    container_name: mysql-lab
    environment:
      MYSQL_ROOT_PASSWORD: CHANGE_ME_ROOT_PASSWORD
      MYSQL_DATABASE: example_db
      MYSQL_USER: example_user
      MYSQL_PASSWORD: CHANGE_ME_USER_PASSWORD
    ports:
      - "3306:3306"
    volumes:
      - mysql_data:/var/lib/mysql
    restart: unless-stopped

  phpmyadmin:
    image: phpmyadmin:5
    container_name: phpmyadmin-lab
    depends_on:
      - mysql
    environment:
      PMA_HOST: mysql
      PMA_PORT: 3306
    ports:
      - "8090:80"
    restart: unless-stopped

volumes:
  mysql_data:

Verify the deployment

  1. Confirm both containers show as running in Portainer.
  2. Open http://optix_edge_ip_address:8090.
  3. Sign in with root and the root password you configured, or with example_user and its password.
  4. Confirm that example_db appears in the navigation panel.
  5. Remove the published MySQL port 3306 if external database clients do not need it.
