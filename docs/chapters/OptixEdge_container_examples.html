Uptime Kuma

Use Uptime Kuma to monitor HTTP, TCP, and other service endpoints through a lightweight web dashboard.

services:
  uptime-kuma:
    image: louislam/uptime-kuma:1
    container_name: uptime-kuma
    ports:
      - "3001:3001"
    volumes:
      - kuma_data:/app/data
    restart: unless-stopped

volumes:
  kuma_data:

Open http://optix_edge_ip_address:3001, create the administrator account, and add only endpoints the device is authorized to monitor.

Mosquitto lab broker

This example deliberately uses a no-auth configuration for lab testing. Do not expose it to production or untrusted networks. 
services:
  mosquitto:
    image: eclipse-mosquitto:2
    container_name: mosquitto-lab
    command: mosquitto -c /mosquitto-no-auth.conf
    ports:
      - "1883:1883"
    volumes:
      - mosquitto_data:/mosquitto/data
      - mosquitto_log:/mosquitto/log
    restart: unless-stopped

volumes:
  mosquitto_data:
  mosquitto_log:

Prometheus and Node Exporter

This stack creates a minimal Prometheus configuration and collects CPU, memory, disk, and network metrics from Node Exporter.

services:
  prometheus-init:
    image: busybox:1.36
    volumes:
      - prometheus_config:/config
    entrypoint: ["/bin/sh", "-c"]
    command:
      - |
        cat > /config/prometheus.yml << 'EOF'
        global:
          scrape_interval: 15s
        scrape_configs:
          - job_name: prometheus
            static_configs:
              - targets: ['localhost:9090']
          - job_name: node-exporter
            static_configs:
              - targets: ['node-exporter:9100']
        EOF
    restart: "no"

  prometheus:
    image: prom/prometheus:v3.5.0
    depends_on:
      prometheus-init:
        condition: service_completed_successfully
    command:
      - --config.file=/config/prometheus.yml
      - --storage.tsdb.path=/prometheus
    ports:
      - "9090:9090"
    volumes:
      - prometheus_data:/prometheus
      - prometheus_config:/config:ro
    restart: unless-stopped

  node-exporter:
    image: prom/node-exporter:v1.9.1
    ports:
      - "9100:9100"
    restart: unless-stopped

volumes:
  prometheus_data:
  prometheus_config:

Useful Prometheus queries

# CPU usage percentage
100 - (avg by (instance) (irate(node_cpu_seconds_total{mode="idle"}[5m])) * 100)

# RAM usage percentage
(1 - (node_memory_MemAvailable_bytes / node_memory_MemTotal_bytes)) * 100

Apache Guacamole

Guacamole requires a database schema, persistent credentials, and careful access control, so it is better treated as an advanced integration rather than a one-file lab stack. Follow the official Guacamole Docker documentation and pin all component versions before deployment.
